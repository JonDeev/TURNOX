# Hoja de evidencia — Fase 0

Crear una copia por sede, unidad y revisión. No sobrescribir una ejecución
anterior.

```text
Sede / entorno:
ID interno de unidad:
Responsable:
Fecha y zona horaria:
Revisión de matriz:
Ventana autorizada:

Fabricante / modelo / serial / firmware / OS (solo evidencia primaria):
Configuración usada (referencias a archivos externos saneados):
Dependencias (switch, servidor, TV, cable, UPS, etc.):

Prueba / ID:
Precondiciones:
Inicio (timestamp):
Fin (timestamp):
Comandos y salida:
Fotografías / capturas / video / logs:
Resultado: PENDIENTE | PASS | FAIL | NO_APLICA
Justificación y acción siguiente:
```

Para `PASS`, la evidencia debe demostrar el criterio objetivo y corresponder a
la unidad configurada. `NO_APLICA` requiere justificación aprobada; no sustituye
una prueba no ejecutada.
